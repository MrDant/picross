# Picross Game

This is a Nonogram game created entirely in HTML, CSS, and JavaScript. It was designed to be played directly in the browser, with flexible grid sizes and additional gameplay mechanics for enhanced player experience.

## Features

- **Custom Grid Sizes**: Choose the exact size of the grid you want to play on.
- **Life System**: Start with 3 lives, and lose one each time you make an incorrect choice.
- **Hints**: Numbers at the top and side of the grid indicate how many cells to fill in each row or column.
- **Cross Placement**: Mark cells with a cross where you are certain there is nothing.
- **Win Message**: Celebrate your victory with a congratulatory message when you solve the puzzle.

## How It Was Made

This project was developed in about 2 hours, without an internet connection, while traveling on a bus to Milan. It demonstrates the capability to focus and create a functional game under unique circumstances.

## How to Play

1. Open the HTML file in any modern web browser.
2. Select the grid size you wish to play with.
3. Use the row and column hints to deduce which cells to fill or mark with a cross.
4. Click on a cell to fill it or right-click to place a cross.
5. Complete the grid without losing all your lives.
