# Nonogram Game

This is a simple Nonogram game created entirely in HTML, CSS, and JavaScript. It was designed to be played directly in the browser, with adjustable difficulty levels and a life system to make the gameplay more engaging.

## Features

- **Difficulty Levels**: Choose between Easy (5x5), Medium (10x10), and Hard (15x15) grids.
- **Life System**: Start with 3 lives, and lose one each time you make an incorrect choice.
- **Hints**: Numbers at the top and side of the grid indicate how many cells to fill in each row or column.
- **Win Message**: Celebrate your victory with a congratulatory message when you solve the puzzle.

## How It Was Made

This project was generated in under 5 minutes using OpenAI's ChatGPT, showcasing the power of AI in rapidly prototyping simple games.

## How to Play

1. Open the HTML file in any modern web browser.
2. Select a difficulty level from the menu.
3. Use the row and column hints to deduce which cells to fill.
4. Click on a cell to fill it or leave it blank.
5. Complete the grid without losing all your lives.
